# GoHighLevel Automation Specialist Portfolio

A React + TypeScript portfolio designed specifically for a GoHighLevel / CRM automation specialist.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## What to customize first

1. Replace `your@email.com` in `src/pages/Home.tsx`.
2. Edit your project content in `src/data/projects.ts`.
3. Replace screenshot placeholders inside each case study with real images.
4. Add Loom URLs to the `loomUrl` field for each project.
5. Add your Upwork, LinkedIn, WhatsApp, or booking link to the contact section.

## Recommended proof for every GHL project

- Funnel screenshot
- Pipeline screenshot
- Workflow screenshot
- Form or survey screenshot
- Calendar screenshot
- 2–4 minute Loom walkthrough
- Short explanation of the business problem and your solution

## Deploy

This project works well with Vercel or Netlify. Push it to GitHub, import the repository, and deploy.
